## Contenido

### Parte 1. Análisis de secuencias FASTA
- Lectura y manipulación de archivos FASTA con Python y Biopython
- Exploración de secuencias
- Cálculo de longitud y estadísticas generales
- Cálculo y análisis del contenido GC (%)

### Parte 2. Anotación taxonómica
- Interpretación de resultados de BLAST
- Manejo de tablas y archivos con Python
- Recuperación de información a partir de números de acceso
- Asignación taxonómica con Biopython
- Consulta de metadatos mediante Bash y NCBI EDirect
- Comparación entre Biopython y Bash + EDirect

### Parte 3. Abundancia y visualización de datos
- Introducción a datos de abundancia
- Manejo de tablas de abundancia
- Filtrado de datos
- Normalización de abundancias
- Visualización y exploración gráfica de los resultados
